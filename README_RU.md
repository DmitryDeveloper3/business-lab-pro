# BUSINESS LAB PRO

Локальное приложение для анализа экономики интернет-магазина и проверки бизнес-решений. Рассчитывает операционную прибыль, безубыточность и маркетинговые KPI, сравнивает сценарии, строит модельные прогнозы и формирует HTML-отчёт.

## Запуск на Mac

```bash
cd ~/Desktop/Portfolio/Python/BUSINESS_LAB_PRO
source .venv/bin/activate
python -m streamlit run streamlit_app.py
```

Для первого запуска на другом компьютере сначала создайте `.venv` через Python 3.14 и установите `requirements.txt`. Также можно открыть `Launch.command` в Finder после установки зависимостей.

1. Выберите русский язык в боковой панели.
2. Загрузите один из четырёх демонстрационных кейсов.
3. В разделе «Экономика бизнеса» измените месячные параметры и нажмите «Применить модель месяца».
4. В симуляторе настройте цену, бюджет, конверсию, CAC, возвраты и эластичность. Сохраните минимум два решения для сравнения.
5. В «Отчёты и экспорт» скачайте JSON, CSV и HTML. Несохранённые изменения теряются после сброса сессии — сохраняйте проект на диск или экспортируйте данные заранее.

Демонстрационные данные синтетические. Все суммы относятся к одному месяцу, без НДС. Возвраты предполагают восстановление товара в запасах и возврат комиссии оплаты, но не расходов обработки. Валюта меняет обозначение без конвертации.

Приложение показывает **операционную прибыль**, не чистую прибыль и не денежный поток. Прогнозы — настраиваемые модели, не машинное обучение и не достоверное предсказание. LTV не рассчитывается без данных об удержании и когортах. Маркетинговые данные ведутся отдельно от финансовой модели; другие затраты привлечения необходимо самостоятельно включить в подходящую финансовую статью, если они должны уменьшать прибыль бизнеса.

Выбор светлой/тёмной темы и валюты USD/EUR/RUB доступен в боковой панели на любом экране. Тема применяется в текущей сессии, в том числе к графикам и ячейкам таблиц. Валюта меняет обозначение сумм текущей модели без пересчёта по курсу; сохранённые сценарии сохраняют исходную валюту. Встроенные кнопки и меню самого Streamlit могут оставаться на английском.

Полные формулы, архитектура, ограничения, инструкция публикации и проверки — в [README.md](README.md), [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), [docs/QA.md](docs/QA.md). Исходники опубликованы: https://github.com/DmitryDeveloper3/business-lab-pro . Публикация самого сайта отслеживается отдельно в docs/DEPLOYMENT.md.

## Новые функции v1.1

- «Проекты и журнал»: постоянное сохранение моделей и параметров в SQLite; отдельный журнал решений. Сохранение — явной кнопкой. JSON-копия содержит модели и параметры; журнал выгружается отдельным CSV.
- «Товары и портфель»: редактируемая экономика SKU и распределение общих расходов без двойного вычитания.
- «Цели и план–факт»: расчёт объёма/цены для целевой прибыли и сравнение календарного плана с фактом.
- «CAC, деньги и промоакции»: допустимая стоимость привлечения, отдельная модель денежных остатков и оценка скидочных акций.
- «Стресс-тест рисков»: воспроизводимые модельные испытания с явными распределениями и квантилями прибыли.

CSV можно скачать кнопкой в боковой панели, у каждой новой таблицы или через «Отчёты и экспорт» → «Центр выгрузки CSV». Доступны отдельный файл и ZIP всех рассчитанных таблиц с допущениями. Кодировка UTF-8 с BOM подходит для кириллицы в Excel. CSV содержит стабильные технические названия столбцов. Отрицательные числа остаются числами; текстовые значения, похожие на формулы, экранируются.

Данные сохранённых проектов находятся в `.local/workspace.sqlite3`, журнал — в той же базе. Файл исключён из Git. Локальная база общая для сессий этой установки; на облачном сервере диск может оказаться временным. Скачивайте резервные копии. Денежный поток не равен прибыли; частота убытка в стресс-тесте относится только к заданным Вами распределениям, а не к реальной вероятности бизнеса.

## Публичное демо

Для Streamlit Community Cloud используется `cloud_app.py`. Проекты разделены по случайному идентификатору сессии: посетители не видят чужие сохранения. Хранение временное — перед выходом скачивайте JSON-копию моделей и CSV журнала. Локальный запуск через `Launch.command` сохраняет прежний режим SQLite на диске.
